# AlgoHar V2 — launch readiness

## Product gate

- [x] More than 20 step-driven visualizations exist in V2.
- [x] Free playground and structured curriculum exist.
- [x] Lesson pages include intuition, pseudocode and complexity.
- [x] Visual engine supports arrays, linear structures, graphs and trees.
- [x] Responsive visual system exists.
- [x] Automated catalog/practice verification, semantic checks, payment-entitlement contract checks, typecheck, lint and production build are part of the V2 CI path.
- [ ] Browser QA on representative desktop and mobile viewports.
- [ ] Human/independent correctness review for every advanced algorithm trace.

## Commercial gate

- [ ] Seller identity/support details published.
- [ ] Public offer/refund terms reviewed for the actual seller/payment model.
- [ ] Privacy page lists real processors and retention periods.
- [ ] Approved Russian payment/receipt path provisioned.
- [x] Server-side signed entitlement protects paid lesson traces.
- [x] Provider-neutral authoritative payment transition contract rejects browser-return truth and verifies idempotent grant, duplicate success, stale events, refund revocation and terminal-state protection in CI.
- [ ] Persist the payment-event/order state with durable unique keys and execute entitlement commands atomically.
- [ ] Connect the approved provider webhook/reconciliation source to that durable transition boundary.
- [ ] Verify one test-provider happy path from authoritative final payment to immediately usable entitlement.
- [ ] Lead and analytics sinks are durable and monitored.
- [ ] Owned domain + HTTPS + production deployment verified.

The checked payment-transition item is a code-level contract only. It does **not** claim that a real provider, durable order database, receipt/fiscalization path or production payment flow exists yet.

## Evidence gate

- [ ] 10 problem/learning interviews or equivalent observed learner sessions.
- [ ] 100 qualified free-algorithm opens before judging early funnel.
- [ ] First 10 verified paid early-access buyers before claiming demand validation.
- [ ] Retention measured from real learner sessions.
- [ ] Any testimonial has explicit consent and a traceable source.

## Marketing gate

Paid acquisition remains zero until commercial and analytics gates pass. Organic founder/SEO distribution may begin once the public free surface is deployed and privacy/seller disclosures are adequate for the data actually collected.
